# Lamma branding profile

This is an opt-in profile for an installation entitled to custom branding. It does
not change installation defaults, license checks, attribution, or pricing plans.
The existing Enterprise community-plan reconciliation resets custom names, logos,
and brand URLs. Persistent white-labeling remains blocked until the deployment's
branding entitlement is verified. Do not disable reconciliation to apply this profile.

## Apply and verify

1. Verify the installation's branding entitlement through the existing licensing workflow.
2. Apply the values in `lamma.yml` using the existing Super Admin installation configuration controls.
   Existing login, dashboard and widget components consume these resolved values.
   The dark logo is the authentic cream Lamma mark, rather than the light wordmark
   whose dark lettering loses contrast on dark backgrounds.
3. Obtain approved brand, widget, terms and privacy URLs. This profile does not change
   their current destinations. Until supplied, existing email/widget links may still
   point to Chatwoot. Review them before production use.
4. Set the deployment's own `FRONTEND_URL`, sender address and SMTP configuration.
   Email layouts now use the resolved installation logo with an absolute URL.
   Invalid URLs, non-HTTP(S) destinations, embedded credentials and unsafe relative
   paths are omitted so malformed branding cannot interrupt transactional email.
   Existing account-specific and installation-specific email template overrides
   continue to take precedence and may need separate review.
5. For each company, configure its own account, inboxes, channels and widget settings.
   The same image can serve each installation; do not bake customer tokens, account
   IDs, domains or sender addresses into it.
6. Check login, dashboard light/dark mode, widget footer, email and browser icon.
   Repeat after plan reconciliation. Upstream manifest/apple/favicon files are used
   only for the default thumbnail; custom thumbnails get a matching touch icon.
   A custom manifest is not generated by this patch.

## Colors

Verified Lamma supplier tokens are signature `#C8543B`, ink `#2A1F1A`, and paper
`#F4ECDF`. Use signature for the existing per-inbox widget color setting. Keep
dashboard semantic status colors and readable light/dark themes unchanged.
No installation-wide palette override or client-specific style injection is added.
